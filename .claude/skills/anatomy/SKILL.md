# אנטומיה: הסבר שאפשר לגעת בו

כשהבעלים שואל "איך X עובד", בונים **קובץ HTML אחד, עצמאי**, שמסביר את X בעזרת מכונה קטנה שאפשר לשחק איתה.

## כללים
- **עובדות רק מהקוד והנתונים של הפרויקט.** קוראים את הקובץ הרלוונטי ב-`affiliate_scraper/` לפני שמסבירים, ולא מנחשים.
  למשל: חיסכון של 5% לפחות (`alerts.py`), ירידה של 10% אחרי 2 בדיקות (`history.py`).
- **מספרי דוגמה מסומנים "דוגמה".** אסור שהם ייראו כמו מחירים אמיתיים.
- **עברית, מימין לשמאל:** `dir="rtl"`. עובד בטלפון: מסך ברוחב 360px, בלי גלילה הצידה.
- **הכול בתוך הקובץ:** CSS ו-JavaScript פנימיים, בלי ספריות חיצוניות ובלי שליחת נתונים לשום מקום.
- **חסכוני:** קובץ אחד, עד כ-300 שורות. מכונה אחת טובה עדיפה על שלוש בינוניות.

## מבנה
1. **שאלה אחת** בראש הדף, למשל: "למה העסקה הזאת לא התפרסמה?"
2. **המכונה:** פקדים (שדה מחיר, מחוון של אחוז חיסכון, כפתורי חנויות) ותוצאה שמשתנה בזמן אמת.
   לדוגמה: "מחיר היום ₪249, מחיר קודם ₪299 → חיסכון 16.7% → ✅ עובר את סף ה-5% → האם זה 'חכם'? (15%+) ✅".
3. **"מה קורה בקוד":** 3–5 שורות שמראות את הכלל האמיתי, עם שם הקובץ.
4. **"נסו בעצמכם":** 2–3 מקרים מעניינים, למשל "מה קורה אם המחיר הקודם הופיע רק פעם אחת?".

## תוצר
- **הקובץ:** `agents_output/explain/<נושא>.html`. אומרים לבעלים איפה הוא, ושאפשר לפתוח אותו בדפדפן במחשב או לשלוח אותו לטלפון.
- **סיכום:** במשפט אחד בצ'אט, מה המכונה מראה.
