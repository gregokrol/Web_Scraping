# שליטה במערכת מהטלפון, דרך Claude

המטרה: לכתוב ל-Claude באפליקציה בטלפון, ו-Claude מריץ פקודות **במחשב שלך** בתיקיית הפרויקט.
אפשר לעדכן קוד, להריץ סריקה, לשנות הגדרות ולתקן תקלות בלי לשבת מול המחשב.

**ההתקנה נעשית פעם אחת, ליד המחשב** (בערך 10 דקות). מאותו רגע הכול נעשה מהטלפון, כל עוד המחשב דלוק.

---

## מה צריך
- המחשב הנייח (Windows), דלוק ומחובר לאינטרנט.
- חשבון Claude, אותו חשבון בטלפון ובמחשב.
- אפליקציית Claude בטלפון.
- הפרויקט כבר מותקן ב-`C:\Projects\Affiliet_bot\Web_Scraping`.

---

## שלב 1: התקנת Claude Code במחשב (פעם אחת)

1. לוחצים על מקש Windows, מקלידים `PowerShell` ולוחצים Enter.
2. מדביקים את השורה הזאת ולוחצים Enter:
   ```
   irm https://claude.ai/install.ps1 | iex
   ```
3. בסוף ההתקנה **סוגרים את חלון PowerShell**, ופותחים חלון **CMD** חדש. רק בחלון חדש הפקודה `claude` מוכרת.
4. מקלידים ולוחצים Enter:
   ```
   claude
   ```
   בפעם הראשונה ייפתח דפדפן לכניסה לחשבון. נכנסים עם **אותו חשבון** שבטלפון.
5. כשמופיע מסך הצ'אט של Claude בחלון, ההתקנה הצליחה. יוצאים עם `/exit`.

> אם מופיע `'claude' is not recognized`, החלון נפתח לפני שההתקנה הסתיימה. סוגרים את כל החלונות ופותחים CMD חדש.
> אם עדיין לא עובד, ההוראות המעודכנות נמצאות ב-https://code.claude.com/docs

## שלב 2: הפעלת השליטה מרחוק

בחלון CMD:
```
cd /d C:\Projects\Affiliet_bot\Web_Scraping
git pull origin claude/web-scraping-v3
claude remote-control
```

- **החלון הזה צריך להישאר פתוח.** כל עוד הוא פתוח, אפשר להתחבר מהטלפון. סגירה שלו מנתקת את החיבור.
- אפשר למזער אותו, ואפשר לנעול את המחשב. רק לא לכבות ולא להעביר למצב שינה.
- **חלופה:** לפתוח את אפליקציית Claude לדסקטופ, להיכנס לטאב Code ולבחור את תיקיית הפרויקט. גם כך הסשן יופיע בטלפון.

### שהמחשב לא יירדם
המחשב צריך להיות ער כדי לענות:
1. הגדרות, מערכת, צריכת חשמל ושינה.
2. "מצב שינה" או "כאשר מחובר לחשמל, העבר למצב שינה אחרי" → **אף פעם**.
3. כיבוי מסך מותר, זה לא מפריע.

## שלב 3: התחברות מהטלפון

1. פותחים את אפליקציית Claude בטלפון, באותו חשבון.
2. נכנסים לאזור **Code**, לרשימת הסשנים. מופיע שם סשן מהמחשב שלך, עם שם התיקייה `Web_Scraping`.
3. נכנסים אליו וכותבים כמו בצ'אט רגיל. Claude מריץ את הפקודות במחשב.
4. **כשמופיעה בקשת אישור** ("Allow?"), מאשרים מהטלפון. Claude שואל לפני פקודות שמשנות דברים, וזה טוב.

---

## מה כותבים מהטלפון: דוגמאות

**ההודעה הראשונה** (השלמת ההגדרות שעוד לא בוצעו). מעתיקים כמו שהיא:
```
תריץ בתיקיית הפרויקט, אחת אחרי השנייה, ותגיד לי מה יצא:
1. git pull origin claude/web-scraping-v3
2. py main.py approval manual
3. py main.py stores disable fox.co.il renuar.co.il twentyfourseven.co.il shilav.co.il megasport.co.il centertoys.co.il amigo.co.il
4. py main.py searches add-preset gaming computers electronics
5. py main.py stores permit ksp.co.il --i-have-written-permission
6. py main.py "https://ksp.co.il/web/promotions" --render js --discover links --include="/web/item/" --max-pages 3 --delay 3
7. py main.py health
```

**שימוש יומיומי:**

| מה רוצים | מה כותבים |
|---|---|
| לעדכן לגרסה חדשה | `תריץ git pull origin claude/web-scraping-v3 ואת הבדיקות` |
| לראות מה מצב המערכת | `תריץ py main.py health ותסכם לי` |
| עסקאות שממתינות לאישור | `תראה לי את העסקאות שממתינות לאישור` (`py main.py alerts --status pending`) |
| לאשר עסקאות | `תאשר את עסקאות 12 ו-14` (`py main.py approve 12 14`) |
| לפרסם את מה שאושר | `תפרסם את העסקאות המאושרות לטלגרם` (`py main.py publish --telegram`) |
| להסיר עסקה | `תסיר את עסקה 8 מהערוץ ומהאתר` (`py main.py withdraw 8`) |
| ריצה מלאה עכשיו | `תריץ את האוטומציה המלאה` (`py main.py run`) |
| להעביר משימה לצוות הסוכנים | `מנהל: תכין 3 טיוטות לאינסטגרם מהעסקאות של היום` |

## אבטחה
- Claude במחשב פועל **רק** דרך החשבון שלך. מי שנכנס לחשבון Claude שלך יכול לשלוט בו. כדאי סיסמה חזקה ואימות דו-שלבי.
- Claude עובד בתיקיית הפרויקט, ומבקש אישור לפני פקודות שמשנות דברים. **קרא מה הוא מבקש לפני שאתה מאשר.**
- הכללים של הפרויקט (`CLAUDE.md` ו-`docs/agents/RULES.md`) חלים גם כאן:
  - אין פרסום, commit או push בלי בקשה שלך
  - אין עקיפת חסימות
  - אין מפתחות בקבצים
- **מפתחות ב-`setx`** (טוקן טלגרם ומפתחות API) עדיין מגדירים רק ליד המחשב, ולא שולחים אותם בצ'אט.
