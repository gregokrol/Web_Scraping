# צוות הסוכנים: מדריך שימוש

בפרויקט יש צוות של 6 סוכני Claude ומנהל אחד. מעבירים משימה למנהל, הוא מפרק אותה, מחלק אותה לסוכנים שעובדים במקביל,
מעביר את התוצרים לבדיקת QA, ומחזיר סיכום.

## הצוות

| סוכן | קובץ | מה הוא עושה |
|---|---|---|
| **המנהל** | `.claude/commands/manager.md` | מקבל משימה, מתכנן, מחלק, מתאם QA ומסכם |
| שומר הנתונים | `.claude/agents/data-keeper.md` | מסד הנתונים, היסטוריית מחירים, שלמות נתונים ודוחות |
| סוכן הסריקה | `.claude/agents/web-scanner.md` | חנויות, דפי מבצעים, robots.txt ותקלות סריקה |
| סוכן ההצלבות | `.claude/agents/price-matcher.md` | התאמת מוצרים בין חנויות והשוואת מחירים אמיתית |
| שיווק לאינסטגרם | `.claude/agents/instagram-marketer.md` | טיוטות פוסטים, קרוסלות, סטוריז ורילס לפי קהל יעד |
| אנליסט משפכים | `.claude/agents/funnel-analyst.md` | איך מביאים תנועה לאינסטגרם, לטלגרם ולאתר, ואיך מודדים |
| QA | `.claude/agents/qa-reviewer.md` | בודק כל תוצר, PASS או FAIL עם הערות לתיקון |

**הכללים המשותפים** לכולם נמצאים ב-[`docs/agents/RULES.md`](agents/RULES.md):
- מכבדים robots.txt ולא עוקפים חסימות
- אין מפתחות בקבצים
- אין פרסום בלי אישור שלך
- רק עובדות מאומתות
- גילוי נאות
- אין קניית עוקבים או ספאם
- לא מדווחים "הושלם" בלי בדיקות

## איך משתמשים

הסוכנים עובדים בתוך **Claude Code** שפתוח על תיקיית הפרויקט: בטאב Code של אפליקציית Claude לדסקטופ, או בשורת הפקודה (`claude`).
תיקיית הפרויקט אצלך: `C:\Projects\Affiliet_bot\Web_Scraping`.

1. מעדכנים: `git pull origin claude/web-scraping-v3`.
2. פותחים את Claude Code על התיקייה.
3. כותבים `/manager` (או "מנהל:") ואחריו המשימה. אפשר גם בשיחה עם Claude בענן על הפרויקט. לדוגמה:

```
/manager תכין לוח תוכן לאינסטגרם לשבוע הקרוב מהעסקאות הכי טובות, לקהל של גיימרים
```

```
/manager בדוק למה החנויות של פוקס ושילב לא החזירו מוצרים אתמול ותקן
```

```
/manager תכנן איך להגיע ל-100 העוקבים הראשונים בערוץ הטלגרם ובאינסטגרם, עם מדידה
```

```
/manager בדוק שכל ההשוואות בין חנויות תקינות ושאין השוואה בין וריאנטים שונים
```

**אפשר גם לפנות לסוכן אחד ישירות,** בלי המנהל. כותבים, למשל: `תשתמש בסוכן qa-reviewer כדי לבדוק את הטיוטה ב-agents_output/...`

## הפעלה מטלגרם

שולחים לבוט בפרטי הודעה כמו `/manager <משימה>`, והסיכום חוזר אליך לטלגרם.

**התקנה (פעם אחת):**
1. מתקינים את Claude Code במחשב. ב-PowerShell:
   ```
   irm https://claude.ai/install.ps1 | iex
   ```
   (או לפי ההוראות ב-https://code.claude.com/docs). אחר כך מריצים `claude` פעם אחת, ונכנסים עם החשבון שלך.
2. מעדכנים את הפרויקט (`git pull origin claude/web-scraping-v3`), ובתפריט בוחרים **32**:
   המאזין יעלה לבד, מוסתר, בכל כניסה ל-Windows, וגם עכשיו.
   כדי להפעיל רק עכשיו בלי התקנה: תפריט **31**.
3. בטלגרם, בצ'אט הפרטי עם הבוט, כותבים `/help`.

**הפקודות בטלגרם:**

| פקודה | מה קורה |
|---|---|
| `/manager <משימה>` (או `מנהל: <משימה>`) | המנהל מפרק את המשימה, מחלק לסוכנים, מעביר QA ומחזיר סיכום |
| `/status` | דוח בדיקה עכשיו |
| `/digest` | הסיכום לשיתוף עכשיו |
| `/help` | רשימת הפקודות |

**אבטחה:**
- רק הודעות מהצ'אט הפרטי שלך (`TELEGRAM_ADMIN_CHAT`) מתקבלות. הודעות מכל אחד אחר, מקבוצה או מערוץ, מתעלמים מהן.
- המשימה עוברת ל-Claude כקלט, ולא כפקודה. אי אפשר "להשתיל" בה פקודת מערכת.
- Claude רץ עם הרשאות מוגבלות:
  - מותר: לקרוא ולערוך קבצי פרויקט, להריץ `py main.py ...` ואת הבדיקות, ו-`git status`, `git diff`, `git log` (קריאה בלבד)
  - **אסור:** commit, push, מחיקות או פקודות מערכת אחרות
- משימה אחת בכל פעם, עם מגבלה של שעה. כל תשובה נשמרת גם ב-`agents_output/telegram/`.
- כל מי שיש לו גישה לחשבון הטלגרם שלך יכול להפעיל את המנהל. כדאי שיהיה לך אימות דו-שלבי בטלגרם.

**הפסקה:** סוגרים את החלון "Telegram manager". כדי שלא יעלה עם Windows: `py main.py telegram-listen --uninstall`.
המחשב צריך להיות דלוק כדי שהמנהל יענה.

## מה קורה מאחורי הקלעים

1. **המנהל** קורא את הכללים ואת `STATUS.md`, וכותב לך תוכנית: טבלה של משימות משנה, מי עושה כל אחת, ומה רץ במקביל.
2. **הסוכנים** עובדים במקביל. משימה שתלויה באחרת מחכה לה, למשל: קודם סריקה, אחר כך השוואה, אחר כך תוכן.
3. **QA** בודק כל תוצר: עובדות מול הנתונים, כללים, בדיקות קוד ועברית. אם יש הערות, הן חוזרות לסוכן שאחראי, שמתקן רק אותן.
   **מקסימום 3 סבבים**, ואחרי זה ההערות הפתוחות מגיעות אליך.
4. **סיכום אליך:** מה נעשה, קבצים, תוצאות בדיקות, מה לא נעשה ולמה, ומה נדרש ממך.

## איפה התוצרים

- **טיוטות ודוחות:** `agents_output/<שם-הסוכן>/` (התיקייה לא נכנסת ל-Git, נשארת אצלך).
- **שינויי קוד:** בקבצי הפרויקט. **אין `commit` ואין `push`** בלי שתבקש.

## חשוב לדעת

- **הסוכנים לא מפרסמים.** לא לאינסטגרם, לא לערוץ ולא לקבוצות. הם מכינים טיוטות ואתה מפרסם.
  אין כרגע חיבור לאינסטגרם, וגם אם יהיה, פרסום יישאר באישור שלך.
- **הסוכנים לא רצים לבד לפי שעון.** הסריקה והפרסום היומיים ממשיכים לרוץ דרך התזמון הרגיל (תפריט 11).
  את הסוכנים מפעילים כשרוצים לשפר, לבדוק או להכין תוכן.
- **צריכה:** כמה סוכנים במקביל צורכים יותר מהמכסה של Claude ממשימה רגילה. למשימה קטנה כדאי לפנות לסוכן אחד ישירות.
- **שינוי סוכן:** כל קובץ ב-`.claude/agents/` הוא טקסט רגיל. אפשר לערוך תפקיד, כלים או כללים. השדה `tools` קובע מה הסוכן מורשה לעשות.
  למשל, ל-QA אין הרשאת עריכה בכוונה, כדי שלא יתקן בעצמו.
