## מטרת הפרויקט

לשדרג את מערכת Web_Scraping הקיימת למערכת חכמה ואוטומטית לאיתור מוצרים, השוואת מחירים, זיהוי עסקאות משתלמות
ויצירת קישורי Affiliate.

## סיכום מצב

| שלב | מצב | בדיקות (Python 3.13 / 3.11) |
|---|---|---|
| P0: באגים, מנוע סריקה, השוואת מחירים | ✅ | 66 עברו / 65 עברו ו-1 דולגה |
| P1: SQLite, היסטוריה, ציונים | ✅ | 81 עברו / 80 עברו ו-1 דולגה |
| P2: אוטומציה, n8n, Dashboard | ✅ | **106 עברו / 105 עברו ו-1 דולגה** |

הבדיקה שדולגה היא של Playwright, שהוא רכיב אופציונלי ולא הותקן בסביבת 3.11.

**מה לא נבדק בפועל:**
- **אתרים אמיתיים:** הגישה לאינטרנט חסומה בסביבת הפיתוח. במקומם נבדק שרת מקומי שמדמה חנויות.
- **Windows אמיתי:** הבדיקות רצו על Linux עם Python 3.11 ו-3.13.
- **n8n אמיתי:** נבדק מול שרת מקומי שמקבל Webhooks.

## 12. תקלות שנמצאו ותוקנו במהלך הפיתוח

- **מחיר ייחוס שגוי בהיסטוריה:** כשאותו מחיר חדש נצפה פעמיים, הוא נחשב למחיר הייחוס של עצמו. התוצאה הייתה שהנחות אמיתיות סומנו כמטעות. תוקן, ונוספה בדיקת רגרסיה.
- **ציון שותפים בלי נתוני עמלה:** Affiliate Score גבוה חושב בלי שום נתון עמלה. היום הציון דורש עמלה מאומתת או נתוני המרות.
- **Cache עם TTL=0:** החזיר דפים שנשמרו באותה שנייה.
- **Timeout:** סווג כשגיאת רשת, ולא כ-timeout.
- **Windows:** פלט עם אימוג'י היה מפיל ריצה מתוזמנת שהפלט שלה נכתב לקובץ לוג.
