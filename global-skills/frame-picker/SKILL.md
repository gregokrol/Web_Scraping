# בחירת הפריים הכי טוב מסרטון, ועריכת התמונה

סקיל כללי לכל פרויקט. כל הקוד נמצא בתיקייה `scripts/` שליד הקובץ הזה.

## התקנה (פעם אחת, כדי שהסקיל יעבוד בכל פרויקט)
מעתיקים את **כל התיקייה** `frame-picker`, כולל `scripts/`, אל תיקיית הסקילים האישית:
- **Windows:** `%USERPROFILE%\.claude\skills\frame-picker\` (עם `SKILL.md` ו-`scripts\` בתוכה)
- **Mac / Linux:** `~/.claude/skills/frame-picker/`

את Claude Code פותחים מחדש אחרי ההעתקה. קובץ ה-`SKILL.md` לבד לא מספיק, כי הוא מפעיל את הסקריפטים שבתיקייה `scripts/`.

## כללים
- **רק סרטון שהמשתמש העלה או נתן לו נתיב,** ושיש לו זכות להשתמש בו. לא מורידים סרטונים מיוטיוב, מאינסטגרם, מטיקטוק או מכל אתר אחר.
- **הסריקה והעריכה רצות מקומית.** שליחת תמונות החוצה קורית רק בדרך ב' (API) או בעריכה מתקדמת עם AI, ובשתיהן רק באישור המשתמש.
- **המקור לא משתנה אף פעם.** כל תוצאה נשמרת כקובץ חדש.
- **אם בפרויקט יש קובץ כללים או מותג** (למשל `CLAUDE.md` או `docs/...`), קוראים אותו ופועלים לפיו: צבעים, לוגו, יחסי גובה-רוחב, ומה אסור להציג.
- **פנים של אנשים:** אם בפריים מופיע אדם, מוודאים שהמשתמש רוצה להשתמש בתמונה שלו.

## מה צריך
- `ffmpeg`. אם הוא לא מותקן, אפשר `pip install imageio-ffmpeg`. מתקינים רק באישור המשתמש.
- Python עם `numpy` ו-`Pillow`.
- לדרך ה-API בלבד (רשות): `anthropic` ומפתח.
- בודקים בתחילת העבודה: `ffmpeg -version`, ו-`python -c "import numpy, PIL"`.

## שלב 1: למצוא את הפריימים הכי טובים
```
python <תיקיית הסקיל>/scripts/frames.py VIDEO.mp4 --top 5
```
- **איפה התוצאות:** כברירת מחדל בתיקייה `<שם הסרטון>-frames` שליד הסרטון. אפשר לשנות עם `--out תיקייה`.
- **מה נשמר:** הקבצים `best-01-at-7.00s.png` וכו' ברזולוציה מלאה, ודף התצוגה `contact-sheet.jpg`.
- **רק חלק מהסרטון:** `--start 3 --end 12`. סורקים צפוף יותר עם `--fps 8`, ומרווח בין פריימים נבחרים קובעים עם `--min-gap 2`.
- **איך נקבע הציון:** חדות 40%, יציבות 25% (בלי תנועה, חיתוך או מעבר באמצע), חשיפה 20% וניגודיות 15%. פריים שחור (fade) לא נבחר. כל פריים נבחר שונה מהאחרים ולא כפילות של אותו שוט.

## שלב 2: בחירה בעזרת AI (Claude)
הסקריפט נותן ציון לפי מספרים. את הבחירה הסופית עושה AI שרואה את התמונות. יש שתי דרכים:

### א. בתוך השיחה (ברירת המחדל, בלי עלות נוספת)
כשהמשתמש מעלה סרטון לשיחה עם Claude (Claude Code או claude.ai), Claude עצמו הוא ה-AI:
1. פותח את `contact-sheet.jpg`, ואז כל אחד מקובצי `best-*.png` בגודל מלא.
2. בוחר כמו עורך תמונות:
   - הנושא חד ושלם
   - העיניים פקוחות
   - אין טשטוש תנועה
   - אין טקסט או גרפיקה באמצע אנימציה
   - שום דבר חשוב לא מוסתר או חתוך בקצה
   - התאורה טובה
3. קובע חיתוך: יחס (לפי היעד, למשל 4:5 לפוסט) ונקודת מרכז (`--focus x,y`), כך שהנושא נשאר בפנים.
4. ממליץ למשתמש על פריים אחד, מסביר בשורה למה, ואומר מה עדיין לא מושלם.

   אם אף פריים לא טוב, סורקים שוב צפוף יותר (`--fps 8`) או בקטע ממוקד (`--start`/`--end`).

### ב. דרך ה-API של Anthropic (כשאין שיחה פתוחה)
לסרטונים רבים בבת אחת, או למשימה מתוזמנת:
```
python <תיקיית הסקיל>/scripts/ai_pick.py <תיקיית התוצאות> --goal "פוסט באינסטגרם של המוצר" --aspect 4:5 --apply final.jpg
```
- **מה נשלח:** דף התצוגה והפריימים המועמדים, בהקטנה, אל Claude (`claude-opus-5-5`).
- **מה חוזר:** JSON עם הפריים שנבחר, הסיבה, הדירוג, הבעיות, היחס ונקודת המרכז. עם `--apply` הסקריפט גם מייצר את התמונה הערוכה.
- **אם המודל מסרב:** מופעל אצלו fallback. ה-API מנסה שוב, לבד, על מודל אחר.
- **מה צריך:** `pip install anthropic` ומפתח (`ANTHROPIC_API_KEY` בסביבה, או `ant auth login`). את המפתח לא כותבים בקובץ או בקוד.
- **עלות:** כל קריאה מחויבת בחשבון של המפתח, בדרך כלל כמה סנטים לסרטון. מריצים רק באישור המשתמש.
- **פרטיות:** התמונות נשלחות ל-Anthropic. לא משתמשים בדרך הזו בסרטון שהמשתמש לא רוצה לשתף, או כשיש בו אנשים שלא הסכימו.

### עריכה מתקדמת עם AI (רשות)
הסרת רקע, הגדלת רזולוציה (upscale), החלפת רקע:
- **רק דרך כלי שמחובר לשיחה,** למשל כלי תמונה של שירות חיצוני.
- **רק באישור מפורש של המשתמש,** כי התמונה עולה לשירות חיצוני ולפעמים זה עולה קרדיטים.
- הסקיל עצמו לא עושה את זה.

## שלב 3: לערוך את התמונה
```
python <תיקיית הסקיל>/scripts/edit_image.py best-01-at-7.00s.png -o final.jpg --aspect 4:5 --resize 1080 --auto
```

| מה | אפשרות |
|---|---|
| חיתוך מדויק | `--crop X,Y,W,H` |
| יחס | `--aspect 1:1` / `4:5` (פוסט באינסטגרם) / `9:16` (סטורי, ריל) / `16:9` (יוטיוב) |
| מרכז החיתוך | `--focus 0.5,0.35` (0 עד 1, משמאל ומלמעלה). למשל, כדי לשמור פנים שנמצאים מעל האמצע |
| גודל | `--resize 1080`, או `--resize 1080x1350` אחרי חיתוך ליחס |
| תיקון אוטומטי | `--auto` (ניגודיות עדינה וחידוד קל) |
| כוונון ידני | `--brightness 1.1 --contrast 1.05 --saturation 1.1 --sharpen 1.2` (הערך 1 משאיר בלי שינוי) |
| סיבוב והיפוך | `--rotate 90`, `--flip` |
| לוגו בפינה | `--watermark logo.png --wm-pos br --wm-size 0.12` |
| פורמט | לפי סיומת הקובץ: `.jpg`, `.png`, `.webp`. איכות: `--quality 92` |

- **פחות זה יותר:** תיקונים עדינים (‏1.05 עד 1.15). תמונה מעובדת מדי נראית מזויפת.
- **אחרי העריכה פותחים את התוצאה ובודקים:** לא נחתך משהו חשוב, הלוגו לא מסתיר טקסט, והצבעים טבעיים.

## מגבלות שכדאי להכיר
- **וידאו HDR מהאייפון** (HLG או Dolby Vision) יוצא בצבעים דהויים, כי אין המרה ל-SDR. בהגדרות המצלמה בוחרים "Most Compatible", או מצלמים בלי HDR.
- **`--top`:** הסקריפט עשוי להחזיר פחות פריימים מהמבוקש כשיש בסרטון מעט שוטים שונים. הוא כותב על כך הערה בפלט.
- **תיקיית התוצאות:** כל ריצה מוחקת את תוצאות ה-`best-*` הקודמות שנמצאות באותה תיקייה.

## מה הסקיל לא עושה
- **טקסט בעברית על התמונה:** Pillow לא מציג עברית מימין לשמאל בצורה נכונה. אם צריך טקסט, בונים אותו ב-HTML ומצלמים עם Playwright, או משתמשים בכלי העיצוב של הפרויקט.
- **הסרת רקע, החלפת אובייקטים ושיפור עם AI:** לא כלולים. זה אפשרי רק בכלי חיצוני ובאישור המשתמש, כי מעלים אליו את התמונה.
